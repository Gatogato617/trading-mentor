TRADING MENTOR — PROTOTIPO PWA

Qué incluye:
- Interfaz adaptable a iPhone.
- Pestañas Inicio, Analizar, Captura e Historial.
- Guarda notas del historial en el navegador.
- Manifiesto PWA y service worker para instalación/uso básico sin conexión.
- NO ejecuta operaciones.
- NO está conectado a precios en vivo ni a IA.
- No envía capturas a ningún servidor.

PUBLICAR GRATIS (desde iPhone):
1. Crea una cuenta en GitHub si no tienes una.
2. Crea un repositorio nuevo llamado trading-mentor, público para usar GitHub Pages gratis.
3. Sube index.html, manifest.webmanifest, sw.js e icon.svg desde la web de GitHub.
4. En el repositorio abre Settings > Pages.
5. En Build and deployment elige Deploy from a branch, rama main y carpeta /(root); guarda.
6. Espera a que GitHub Pages publique el sitio y abre la URL que GitHub te muestre.
7. En Safari toca Compartir > Añadir a pantalla de inicio > Añadir.

IMPORTANTE:
- No guardes API keys, contraseñas o tokens dentro de estos archivos.
- Esta primera versión es una interfaz de prototipo, no un sistema de señales.
- Para añadir precios en vivo, calendario económico y análisis de IA necesitaremos una API y un backend seguro. Algunas fuentes ofrecen niveles gratuitos limitados; revisaremos límites, símbolos, retraso, permisos y CORS antes de conectarlas.
- No uses una señal del bot como garantía de beneficio. Valida cualquier estrategia con pruebas históricas y demo.
